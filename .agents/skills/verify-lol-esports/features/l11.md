## Gotchas

Use `tests/conditionalPowerResultBrowser.test.ts` and the exported `conditionalPowerReceiptFixture` in `tests/fixtures/conditionalPowerFixtures.ts` for numeric component proof. Its start time is in the past, so use its pinned browser clock. The fixed ranking snapshot alone does not supply the exact producer companion. A missing companion fails numeric acceptance. Synthetic acceptance does not prove real-generation accuracy.
