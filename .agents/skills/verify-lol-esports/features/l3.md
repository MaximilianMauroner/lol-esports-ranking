# L3: Team and player details

## Sub-features

Team details, player disclosure, roster, rating timeline, and recent matches.

## How to get to it (user POV)

Open Rankings, then click a team name in the table.

## Driving it with T3 preview

Use the selected team button from the current snapshot. Require the dialog named for that team plus ` details`. Inspect the region `Power over time`, open the `Players` disclosure, use the native `Player stats` select when present, then close with the dialog button `Close`. Select another team and check that its name and history replace the first.

## Gotchas

A loaded player directory can show `Source gap`; fewer than two history points cannot produce a chart. These are supported empty states. A journey that requires populated players or history still needs those inputs. Failed requests are separate from valid empty data.
