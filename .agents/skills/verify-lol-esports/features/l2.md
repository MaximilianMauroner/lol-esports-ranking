Use the same open tab at mobile and desktop widths for the address checks:

1. Open typed or linked Rankings hashes with region, team search, tournament,
   eligibility, sort, page size and page. Compare each board with a reload of
   that address. Back and Forward must restore the addressed board.
2. Reload `sort=rating` without `dir`. Power must remain highest first.
   A valid addressed page must remain selected after tournament options load.
3. Open and close a team detail. Keep the tournament filter. An exact tournament
   must include its unranked participants without changing the eligibility
   setting for the general board.
4. Follow the Rankings tab and the logo from a filtered board and from Matches.
   Both open the clean board for the selected scope, without the earlier
   filters or Matches page and page size.
5. Change a filter through its control. The address must match the board.
   Filter controls use `replaceState`, so these changes do not add history
   entries. Back and Forward apply to navigated addresses.
